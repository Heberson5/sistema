# Frontend — Sistema de Gestão Funerária

Aplicação web em Next.js + React + Tailwind CSS. Veja o
[README principal](../README.md) para instruções completas de setup e
arquitetura.

## Comandos úteis

```bash
npm run dev     # inicia em modo desenvolvimento — http://localhost:3000
npm run build   # build de produção
npm run start   # roda o build de produção
```

Configure a URL da API em `.env.local` (`NEXT_PUBLIC_API_URL`).
