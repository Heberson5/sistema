# Backend — Sistema de Gestão Funerária

API REST em NestJS + Prisma + PostgreSQL. Veja o [README principal](../README.md)
para instruções completas de setup e arquitetura.

## Comandos úteis

```bash
npm run start:dev        # inicia em modo desenvolvimento (watch)
npx prisma migrate dev   # aplica migrações do schema
npx prisma db seed       # popula dados de exemplo
npx prisma studio        # interface visual do banco de dados
```

Documentação interativa da API (Swagger): `http://localhost:3001/api/docs`.
